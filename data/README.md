# SCORE Observation Data

This directory contains optical observations of HULIANWANG DIGUI satellites obtained from the Satellite Constellation Observation Repository (SCORE), operated through the IAU Centre for the Protection of the Dark and Quiet Sky (IAU CPS) SatHub.

The data are used by `examples/guowang_final_brightness_model.py` to compare model-predicted satellite brightness with ground-based photometric observations.
